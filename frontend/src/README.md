# frontend/src/

| Carpeta | Contenido |
|---|---|
| `pages/` | Pantallas completas |
| `components/` | Componentes reutilizables |
| `security/` | Renderizado seguro de contenido no confiable |
| `services/` | Acceso HTTP tipado |
| `App.tsx` | Resolución de sesión y enrutado mínimo |
| `main.tsx` | Punto de entrada |
| `styles.css` | Tema claro/oscuro, responsive, foco visible |

El frontend **refleja** lo que el backend responde; no decide qué puede ver el
usuario.
