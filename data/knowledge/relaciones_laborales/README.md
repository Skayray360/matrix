# relaciones_laborales/ (compatibilidad)

Corpus heredado de Relaciones Laborales. La ruta conserva la categoría efectiva
`relaciones_laborales` para mantener funcional el paquete anterior.

- Entradas: reglamentos y procedimientos oficiales ya existentes.
- Salida: chunks corporativos sujetos al filtro de Relaciones Laborales.
- Dependencias: política y grupos autorizados para el dominio.

Use `especializadas/relaciones_laborales/` para nuevas publicaciones. Mantenga
expedientes personales fuera del corpus general y aplique el proceso documental
aprobado. Este `README.md` se excluye de la ingesta.
