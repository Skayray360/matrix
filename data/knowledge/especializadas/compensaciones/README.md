# compensaciones/

Categoría efectiva: `compensaciones`.

| Nivel | Grupo |
|---|---|
| Administrador | `HCM_ADM_COMPENSACIONES_MX` |
| Coordinador | `HCM_COORD_COMPENSACIONES_MX` |

Contiene políticas y procesos especializados de Compensaciones. Requiere además
`HCM_EMP_BASICO_MX`; no concede Talento ni Administración de Personal salvo que
la identidad tenga también esos grupos.
