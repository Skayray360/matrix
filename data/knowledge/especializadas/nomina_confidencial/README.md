# nomina_confidencial/

Categoría efectiva: `nomina_confidencial`; acceso nominal y fuera de wildcard.

| Nivel | Grupo |
|---|---|
| Administrador | `HCM_ADM_NOMINA_CONF_MX` |
| Coordinador | `HCM_COORD_NOMINA_CONF_MX` |

Contiene únicamente documentación clasificada como Nómina Confidencial.
Requiere además `HCM_EMP_BASICO_MX`. Ni los grupos de Nómina General ni un rol
administrativo genérico deben recuperar, enumerar o inferir este repositorio.
