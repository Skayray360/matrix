# nomina_general/

Categoría efectiva: `nomina_general`.

| Nivel | Grupo |
|---|---|
| Administrador | `HCM_ADM_NOMINA_GRAL_MX` |
| Coordinador | `HCM_COORD_NOMINA_GRAL_MX` |

Contiene calendarios, procesos y políticas operativas de Nómina General.
Requiere además `HCM_EMP_BASICO_MX`. Estos grupos no conceden acceso a
`nomina_confidencial`.
