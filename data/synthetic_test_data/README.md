# data/synthetic_test_data/

Datos sintéticos auxiliares para pruebas manuales y demostraciones.

**Nunca información real.** Los fixtures de las pruebas automatizadas se generan
en memoria dentro de cada prueba (`tests/unit/test_loaders.py`), de modo que no
haya binarios opacos en el repositorio.

Si añade archivos aquí, márquelos explícitamente como sintéticos en su contenido.
