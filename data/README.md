# data/

| Carpeta | Contenido |
|---|---|
| `knowledge/general/` | Documentación común para `HCM_EMP_BASICO_MX`, organizada por tema |
| `knowledge/especializadas/` | Repositorios por dominio con grupos HCM explícitos |
| `synthetic_test_data/` | Datos sintéticos auxiliares para pruebas |

**No versionar documentos empresariales reales.** El `.gitignore` excluye
binarios bajo `knowledge/`; el corpus que se distribuye es sintético y está
marcado como tal en el propio texto de cada documento.

Nómina General y Nómina Confidencial son dominios distintos. La clasificación
se hace por la ruta antes de construir el índice; el modelo no decide permisos.
